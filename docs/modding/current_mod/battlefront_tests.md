# Battlefront: test notebook

The in-game smoke tests of Battlefront: what each one checks and its last result. The scenarios
live in [`battlefront_smoke.gc`](battlefront_smoke.gc), one numbered scenario per run; the
`smoke-tests` skill explains the runner. Every scenario boots retail (the launcher's boot), loads
save slot 1 from the title screen and drives the mod's real menus with the pad: the Mods menu
(L3 + SELECT) and START > Options > Gamemode > Battlefront. Nothing is saved.

## Run a test

```bash
python scripts/modding/smoke_test.py install jak3 docs/modding/current_mod/battlefront_smoke.gc --scenario <n>
task compile-check
python scripts/modding/smoke_test.py run jak3 <test-id> --retail --timeout 540
python scripts/modding/smoke_test.py remove jak3
task compile-check
```

- Edit the scenario in `battlefront_smoke.gc`, then install it again: the build compiles the copy.
- `run` kills the game when the scenario prints `SMOKE DONE` or at the timeout. After a run, check
  that no game process is left (`tasklist /FI "IMAGENAME eq gk.exe"`), above all after a crash or
  an interrupted runner.
- Scenarios 2 to 4 need a save slot 1 from which START > Options is reachable; the battle takes
  the player to Haven City by itself.
- Results, the full log and the screenshots land in `out/smoke/<test-id>/`. A line
  `SMOKE step <action>` precedes every action, so the last one before a crash names it.
